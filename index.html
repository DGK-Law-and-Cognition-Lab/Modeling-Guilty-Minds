Modeling Guilty Minds

How laypeople infer Model Penal Code mental states from the facts of a case: two studies
Author and institutional details are withheld for masked review.

The Studies

Both studies ask whether laypeople sort a defendant's mental state into the Model Penal Code's categories when they have to infer it from the facts of a case rather than read it from a label. In every case a man agrees to carry a package across a national border, and six binary features vary across 64 versions of the case: who asks him (his uncle or a biker), the package (gift-wrapped or a duffel bag), how he learns about the contents (the source tells him without being asked, or he asks), payment ($1,000 or none), the border (Canada or Mexico), and what the package holds (fentanyl, or a medicine for a rare disease that is not approved in the United States). Each participant judged five cases. For each case they chose which of four descriptions the scenario proved beyond a reasonable doubt (the descriptions correspond to Knowledge, Recklessness, Negligence and Blamelessness, and were shown without those labels), rated on a 0 to 100 slider how certain the man was that the package held illicit material, and explained their choice in writing.

Study 1 (212 undergraduates, 1,060 cases) found that Knowledge choices came with lower certainty ratings than Recklessness choices, the reverse of the order the Code implies. Study 2 (262 jury-eligible US adults, 1,310 cases) repeated the Study 1 task unchanged and then showed each case again with three yes-or-no questions about the elements: whether the scenario proved beyond a reasonable doubt that, when he crossed the border, the man knew or was practically certain that illicit material was in the package; that he was aware of a substantial risk that it was; and that a reasonably careful person in his position would have been aware of that risk.

Repository Contents

Study 1

Data
One row per case: the choice, the certainty rating, the written justification, response times and demographics.
Experiment
The jsPsych task as it ran, the 64 vignettes, and the algorithm that assigned each participant's five cases.
Analysis
R Markdown for the cumulative link mixed models and the power analysis; a Python notebook for the random forests, SHAP, RSA and text analyses.
Figures
The Study 1 figures in color and grayscale (PDF).

Study 2

Data
One row per case and one per participant, with participant codes in place of Prolific IDs, and the code given to every justification in both studies.
Experiment
The jsPsych task as it ran on Pavlovia, with the eligibility item, the element questions and the comprehension item, and the function that kept the vignette counts current.
Coding Protocol
The check set and hand codes, the frozen coding prompt and its freeze record, and every model response and inference result.
Analysis and Output
The scripts in the order they ran, from the registered exclusions to the frozen analysis script, their reports, tables and figures, and a README that describes each step.
